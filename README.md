# The One-Line Laugh

Entry for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f?ref=41fw6r6c) on [make.fun](https://make.fun/r/41fw6r6c).

## Run

```bash
node main.ts
```

Writes a deterministic, single-sentence UTF-8 one-liner (within 200 characters, no trailing newline) to `/output/entry.txt` (or `<output-dir>/entry.txt` when an optional output directory argument is passed for local testing).
